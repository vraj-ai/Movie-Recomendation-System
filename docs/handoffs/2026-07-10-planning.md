## What this project is

An **algorithm experiment** (not a production service): implement four movie
recommendation approaches and compare them head-to-head on one dataset with one
set of metrics. Full rationale in the glossary and spec below.

## Locked decisions (the forks that were settled)

1. **Purpose:** algorithm experiment — compare approaches, measure metrics.
2. **Data:** MovieLens `ml-latest-small` ratings ⨝ TMDB metadata via `links.csv`.
3. **TMDB source:** TMDB REST API + local disk cache; API key from env var only.
4. **Approaches (4):** popularity baseline · content-based (TMDB) · matrix
   factorization (SVD) · hybrid (content+CF).
5. **Evaluation:** ranking metrics (Precision@K / Recall@K / NDCG@K) primary +
   RMSE/MAE for rating-predictors; per-user hold-out split.
6. **Stack:** Python · scikit-learn (TF-IDF, cosine, TruncatedSVD/NMF) · scipy
   sparse · pandas/numpy. **No** `scikit-surprise` (install/maintenance friction).
7. **Interface:** CLI — `run` (full pipeline → comparison table md+CSV) and
   `recommend` (top-N for user / similar-to-movie).

## Invariants (must hold; restated in tickets)

- **Perf:** cold enrichment <15min · warm load <20s · per-model train <60s · full
  `run` <5min warm · `recommend` <1s · memory <2GB.
- **Failure:** fail fast on missing/invalid key & dataset-download failure;
  backoff+skip on transient TMDB errors; honor 429; coerce malformed data;
  degrade on no-TMDB-match; detect+refetch corrupt cache entries.
- **Security:** key only from env/gitignored `.env`, never committed/logged;
  `data/` & `cache/` gitignored; public/anonymized data only.
